# 🌸 성경 타자 · 개역개정

장모님을 위한 **성경 필사 타자** 웹앱입니다. 한 절씩 말씀을 보면서 따라 치면, 맞은 글자는 초록으로,
틀린 글자는 빨갛게 표시되고, 한 **장**을 다 치면 **꽃 도장 🌸**이 쾅! 찍혀 도장판에 쌓입니다.

- 주소: **https://bswjys.github.io/bible-typing/**
- 컴퓨터(PC) 화면에 맞춰 만들었고, 태블릿·휴대폰에서도 깨지지 않습니다.
- 본문: 대한성서공회 **개역개정** — 구약 39권 · 신약 27권 = **66권 1,189장 31,088절** 전부.

## 쓰는 법 (컴퓨터)

1. 브라우저(크롬·엣지)에서 위 주소를 엽니다.
2. `Ctrl + D` 로 **즐겨찾기**에 넣어 두면 다음부터 한 번에 열 수 있어요.
3. 왼쪽에서 성경 책과 장을 고르고, 가운데 **‘여기에 따라 치세요’** 칸을 누른 뒤 말씀을 따라 칩니다.

| 하고 싶은 것 | 방법 |
| --- | --- |
| 글자 크기 바꾸기 | 오른쪽 위 **보통 / 크게 / 아주 크게** |
| 다음 절로 | 절을 정확히 다 치면 **저절로** 넘어가요 (Enter 도 됩니다) |
| 이전 절 | **← 이전 절** |
| 한 절 다시 쓰기 | **다시 쓰기** |
| 다른 성경 책·장 | 왼쪽 **성경 고르기** (시편·잠언·요한복음 등은 위쪽 추천 칩) |
| 도장 보기 | 오른쪽 위 **🌸 도장판** |

> 띄어쓰기와 쉼표·마침표는 **저절로 들어갑니다.** 글자만 따라 치시면 돼요.

## 무엇이 쌓이나요

- **한 절**을 마칠 때마다 꽃잎이 반짝 ✨ (오늘 친 절 수가 올라가요)
- **한 장**을 마치면 **“참 잘하셨어요! 🌸”** 꽃 도장이 쾅! 찍히고 도장판에 하나씩 쌓입니다
- 오른쪽에 **오늘 딴 꽃 도장**, **누적 친 절 · 마친 장 · 꽃 도장 수**, **달력(도장 찍은 날)** 이 보입니다
- 마지막으로 치던 자리는 자동 저장돼서, 다음에 켜면 **그 자리에서 이어서** 칠 수 있어요

## 기록 보관

- 기록은 **이 컴퓨터의 브라우저에만** 저장됩니다(서버로 보내지 않아요).
- 컴퓨터를 바꾸거나 브라우저 기록을 지울 때는 **도장판 → JSON 내보내기** 로 파일을 받아 두고,
  새 곳에서 **JSON 불러오기** 로 되살리면 됩니다.

## 폴더 구조

```
index.html            화면
styles.css            디자인 (크림색 종이 질감 · 글자 크기 3단계)
app.js                타자 채점 · 한글 IME 조합 처리 · 꽃 도장 · 저장
data/index.json       66권 목록 (장·절 수)
data/{code}.json      권별 본문 (예: data/psa.json = 시편)
build_data.py         개역개정 원본 JSON → 권별 data 파일 생성
make_icons.py         꽃 아이콘 생성
test_bible_typing.py  Playwright 검증 (67항목)
sw.js                 오프라인 캐시
```

## 타자 판정 방식

- 말씀에서 **띄어쓰기·문장부호를 뺀 글자**만 비교합니다. 그래서 쉼표를 몰라도 술술 넘어갑니다.
- 한글 **IME 조합 중**에는 아직 판정하지 않아서, `ㅌ` → `태` 처럼 만드는 도중에 빨간 오타로 깜빡이지 않습니다.
- 틀린 글자부터는 빨갛게 표시되고, 고쳐 치면 그 자리에서 바로 통과됩니다.
