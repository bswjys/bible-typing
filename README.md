# 🌸 솔까 김안숙 권사 전용 성경 타이핑

장모님을 위한 **성경 필사 타자** 웹앱입니다. 한 절씩 말씀을 보면서 따라 치면, 맞은 글자는 초록으로,
틀린 글자는 빨갛게 표시되고, 한 **장**을 다 치면 **꽃 도장 🌸**이 쾅! 찍혀 도장판에 쌓입니다.

- 주소: **https://bswjys.github.io/bible-typing/**
- 컴퓨터(PC) 화면에 맞춰 만들었고, 태블릿·휴대폰에서도 깨지지 않습니다.
- 본문: 대한성서공회 **개역개정** — 구약 39권 · 신약 27권 = **66권 1,189장 31,088절** 전부.

## 쓰는 법 (컴퓨터)

1. 브라우저(크롬·엣지)에서 위 주소를 엽니다.
2. `Ctrl + D` 로 **즐겨찾기**에 넣어 두면 다음부터 한 번에 열 수 있어요.
3. 왼쪽에서 성경 책과 장을 고르고, 가운데 **‘여기에 따라 치세요’** 칸을 누른 뒤 말씀을 따라 칩니다.

| 하고 싶은 것 | 방법 |
| --- | --- |
| 글자 크기 바꾸기 | 오른쪽 위 **보통 / 크게 / 아주 크게** |
| 다음 절로 | 절을 정확히 다 치면 **저절로** 넘어가요 (Enter 도 됩니다) |
| 이전 절 | **← 이전 절** |
| 한 절 다시 쓰기 | **다시 쓰기** |
| 다른 성경 책·장 | 왼쪽 **성경 고르기** (시편·잠언·요한복음 등은 위쪽 추천 칩) |
| 도장 보기 | 오른쪽 위 **🌸 도장판** |

> 띄어쓰기와 쉼표·마침표는 **저절로 들어갑니다.** 글자만 따라 치시면 돼요.

## 무엇이 쌓이나요

- **한 절**을 마칠 때마다 꽃잎이 반짝 ✨ (오늘 친 절 수가 올라가요)
- **한 장**을 마치면 **“참 잘하셨어요! 🌸”** 꽃 도장이 쾅! 찍히고 도장판에 하나씩 쌓입니다
- 오른쪽에 **오늘 딴 꽃 도장**, **누적 친 절 · 마친 장 · 꽃 도장 수**, **달력(도장 찍은 날)** 이 보입니다
- 마지막으로 치던 자리는 자동 저장돼서, 다음에 켜면 **그 자리에서 이어서** 칠 수 있어요

## 🌱 자동 출석 · 연속 출석 · 칭호

- 오늘 **1절만 마쳐도 자동으로 출석**입니다. 오른쪽 **출석 꽃밭** 카드에 `✅ 오늘 출석`, `🔥 N일 연속`,
  최근 14일 꽃밭이 보이고, 달력의 오늘 칸에도 출석 표시(✅)가 붙습니다.
- 누적 완료 절 수에 따라 이름 옆에 칭호가 붙습니다.
  - `🌱 새싹 타자수` (0~29절) · `🌸 말씀 꽃길` (30~199절) · `✍️ 성경 서기관` (200~999절) · `👑 은혜의 장인` (1,000절~)
  - 순위표(TOP 5)와 명예의 전당에 **칭호 · 연속 출석 일수**가 함께 보입니다.

## 📅 이달의 성경 · 월간 완필 상장

- 오른쪽 **📅 이달의 성경** 카드에서 그 달의 목표 성경을 66권 중에 고릅니다(추천도 보여 줍니다).
- 카드에 `마태복음 12 / 28장`처럼 **이번 달에 마친 장 수**가 진행률 막대와 함께 보입니다.
- 그 달 안에 그 권의 모든 장을 마치면 **「이달의 성경 완필 상장」**이 자동으로 떠서,
  `2026년 11월 이달의 성경 [마태복음] 전 28장을 정성으로 완필하셨습니다.`가 적히고 **PNG 저장 · 인쇄**가 됩니다.
  받은 상장은 **내 상장함**에 모입니다.
- 함께 쓰는 중이면 이달의 성경은 방(`/monthlyGoal/{YYYY-MM}`)에 저장되어 **모임 전체가 같은 목표**를 함께 봅니다(누구나 바꿀 수 있어요).

## 💬 축하 소식 게시판

- 상단 **💬 축하 소식** 버튼을 누르면 게시판이 열립니다. 새 글·새 답글이 있으면 분홍 알림 배지가 반짝입니다.
- 한 권 완필 · 이달의 성경 완필 · 연속 출석(3·7·14·30일 …)을 달성하면 축하 글이 **저절로 올라갑니다**.
  - `🎉 {이름}님이 [{권명}]을 완필했어요!`
  - `🏆 {이름}님이 {M}월 이달의 성경 [{권명}]을 완필했어요!`
  - `🔥 {이름}님이 {N}일 연속 출석을 달성했어요!`
- **한 줄 응원·근황**을 직접 남기고, 각 글에 **답글**(`축하드려요! 🌸`)을 달 수 있습니다.
- 다른 사람이 글·답글을 남기면 `💬 {작성자}님이 새 축하/답글을 남겼어요!` 토스트가 뜨고 배지가 반짝여 바로 확인하러 갈 수 있어요(실시간).

## 🌸 함께 쓰기 — 가족·친구와 같은 방에서

- 오른쪽 위 **🌸 함께 쓰기 켜기** → 내 이름(예: `김안숙 권사`)과 방 코드(예: `안숙가족`)를 정하면
  그 방에 들어옵니다. **초대 링크 복사**로 `?room=방코드` 링크를 보내면 상대는 코드 입력 없이 바로 들어와요.
- 연결되면 제목 옆에 **· 함께 쓰는 중** 배지, 위쪽에 초록 점 **● 함께 쓰는 중 · 방코드**가 보입니다.
- 이름은 `localStorage`에 저장되어 새로고침해도 그대로이고, **🌸 함께 쓰기 설정**에서 언제든 바꿀 수 있습니다.
- 절을 하나 완료할 때마다 내 기록(오늘 절·글자 수, 누적 장·완필 권·1독, 박수)이 방에 올라가고,
  다른 사람의 기록은 **실시간(SSE, 안 되면 5초 폴링)** 으로 받아옵니다.
- 이 기기에 이미 쌓인 기록은 방에 들어갈 때 **합산**되어 사라지지 않습니다.

## 🏆 오늘의 타자 등수 · 명예의 전당 · 완필 상장

- 오른쪽 **오늘의 타자 등수 TOP 5** — 오늘(한국 시간) 완료한 **절 수** 순, 같으면 **글자 수** 순.
  - 1등 🥇 **금꽃잎**, 2등 🥈 **은꽃**, 3등 🥉 **동꽃**, 4등 🌱 새싹, 5등 🌷 꽃봉오리
  - 내가 1등에 오르면 **“🌼 김안숙 권사님이 오늘 1등 금꽃잎에 오르셨어요!”** 축하가 뜹니다.
  - 각 사람 옆 **👏 버튼**으로 응원의 박수를 보내고, 내 박수가 늘면 **“👏 누군가 응원의 박수를 보냈어요!”**
  - 내가 5등 밖이면 아래에 **내 순위**가 작게 표시됩니다.
- **🏆 명예의 전당** — 방 사람들의 누적 완필 권 수 · 누적 완료 장 · 1독 달성 · 누적 박수
- **📜 내 상장함** — 한 권을 다 치면 **금빛 테두리 완필 상장**이 자동으로 뜨고(성함·완필 내용·날짜·금빛 직인),
  **PNG 이미지로 저장**하거나 **인쇄하기** 할 수 있습니다. 상장은 상장함에 모여 다시 볼 수 있어요.
  (시연용 **상장 미리보기** 버튼도 있습니다 — 창세기 상장)

## 기록 보관

- 기록은 기본적으로 **이 브라우저에** 저장됩니다. 함께 쓰기를 켜면 방 사람들과 오늘 등수·완필 기록만 공유됩니다.
- 컴퓨터를 바꾸거나 브라우저 기록을 지울 때는 **도장판 → JSON 내보내기** 로 파일을 받아 두고,
  새 곳에서 **JSON 불러오기** 로 되살리면 됩니다.

## 타자 판정 방식

- 말씀에서 **띄어쓰기·문장부호를 뺀 글자**만 비교합니다. 그래서 쉼표를 몰라도 술술 넘어갑니다.
- 한글 **IME 조합 중**에는 아직 판정하지 않아서, `ㅌ` → `태` 처럼 만드는 도중에 빨간 오타로 깜빡이지 않습니다.
- 틀린 글자부터는 빨갛게 표시되고, 고쳐 치면 그 자리에서 바로 통과됩니다.

## 함께 쓰기 저장소

- Firebase Realtime Database `baby-feeding-9f820` 의 **`/bible_typing_rooms/{방코드}`** 만 사용합니다.
  (수유 앱 `/rooms`, 하트노트 `/couple_rooms` 와 겹치지 않아요.)
- `members/{내ID}` = 이름·오늘 절/글자 수·누적 장·완필 권·1독·박수·연속 출석,
  `claps/{받는사람}/{박수ID}` = 박수 한 번,
  `monthlyGoal/{YYYY-MM}` = 그 달의 목표 성경, `posts/{글ID}` = 축하 글, `posts/{글ID}/replies/{답글ID}` = 답글.
